# Asteroids Game

Классическая игра "Астероиды" на Python с использованием библиотеки pygame.

## Описание игры

Управляйте космическим кораблём, уничтожайте астероиды и собирайте очки. Избегайте столкновений с астероидами и ограничивайте время нахождения на одной позиции.

## Основной функционал

### Игровые объекты

- **Игрок (Космический корабль)**: управляемый объект с возможностью вращения, перемещения и стрельбы
- **Астероиды**: разрушаемые объекты трёх размеров (маленькие, средние, большие)
- **Снаряды**: лазерные выстрелы игрока для уничтожения астероидов

### Механики игры

- **Движение**: инерционная физика с ускорением и замедлением
- **Стрельба**: возможность выпускать снаряды с ограничением по количеству на экране
- **Разрушение астероидов**: большие астероиды распадаются на средние, средние на маленькие
- **Очки**: начисляются за уничтожение астероидов (чем меньше астероид, тем больше очков)
- **Жизни**: игрок начинает с 3 жизнями
- **Безопасность**: защита от кампинга (наказание за длительное нахождение в одной точке)
- **Неуязвимость**: кратковременная защита после возрождения

## Требования

Для запуска игры необходимы:

- Python 3.x
- Библиотека pygame

## Установка зависимостей

Установите библиотеку pygame с помощью pip:

```bash
pip install pygame
```

## Запуск игры

1. Убедитесь, что все файлы проекта находятся в одной директории:
   - `main.py` - главный файл игры
   - `player.py` - класс игрока
   - `asteroid.py` - класс астероида
   - `asteroidfield.py` - менеджер поля астероидов
   - `shot.py` - класс снаряда
   - `circleshape.py` - базовый класс для круглых объектов
   - `constants.py` - константы игры

2. Запустите игру:

```bash
python main.py
```

## Управление

### Клавиши управления

- **W** или **↑ (Стрелка вверх)**: вперёд/ускорение
- **A** или **← (Стрелка влево)**: поворот влево
- **D** или **→ (Стрелка вправо)**: поворот вправо
- **S** или **↓ (Стрелка вниз)**: назад/торможение
- **SPACE (Пробел)**: стрельба

## Правила игры

### Цель
Уничтожайте астероиды и набирайте максимальное количество очков.

### Система очков
- **Большой астероид**: 20 очков
- **Средний астероид**: 50 очков (при разрушении большого)
- **Маленький астероид**: 100 очков (при разрушении среднего)

### Жизни и Game Over
- Игра начинается с 3 жизнями
- При столкновении с астероидом теряется одна жизнь
- После потери жизни происходит возрождение в центре экрана с кратковременной неуязвимостью
- При потере всех жизней - игра окончена

### Механика безопасности
- Игрок получает предупреждение, если находится в одной позиции более 3 секунд
- После 5 секунд на одной позиции игра считается проигранной (анти-камп система)

## Структура проекта

### Основные файлы

- **main.py** - точка входа, главный игровой цикл, обработка событий
- **player.py** - класс Player, управление кораблём
- **asteroid.py** - класс Asteroid, поведение астероидов
- **asteroidfield.py** - класс AsteroidField, генерация и управление астероидами
- **shot.py** - класс Shot, снаряды игрока
- **circleshhape.py** - базовый класс CircleShape для круглых объектов
- **constants.py** - константы игры (SCREEN_WIDTH, SCREEN_HEIGHT и др.)
- **logger.py** - система логирования

### Классы

- `CircleShape`: базовый класс для всех круглых объектов
- `Player`: управляемый игроком корабль
- `Asteroid`: астероиды с разными размерами и скоростью
- `AsteroidField`: менеджер поля астероидов
- `Shot`: снаряды для уничтожения астероидов

## Особенности реализации

- **Объектно-ориентированный подход**: все игровые объекты наследуются от базового класса
- **Коллизии**: обнаружение столкновений на основе радиусов объектов
- **Разделение астероидов**: при уничтожении большие астероиды делятся на два меньших
- **Инерционная физика**: реалистичное движение с ускорением и замедлением
- **Логирование**: отладочная информация записывается в `app.log`

## Troubleshooting

### Игра не запускается
- Убедитесь, что установлен Python 3.x
- Проверьте, что pygame установлен: `pip show pygame`
- Убедитесь, что все файлы находятся в одной директории

### Окно игры не отображается корректно
- Проверьте разрешение экрана в `constants.py` (SCREEN_WIDTH и SCREEN_HEIGHT)
- Обновите драйверы видеокарты

### Проблемы с управлением
- Проверьте раскладку клавиатуры (должна быть английская)
- Убедитесь, что окно игры активно (в фокусе)
